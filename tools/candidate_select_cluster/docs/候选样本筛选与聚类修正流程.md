## 一、总体目标

对每道**合格题目**（样本数 ≥ 40）构造互补的两套数据：

1. **select**：每题固定 8 个 JPG–JSON 数据对，用作基准/评测候选；
2. **raw**：该题其余样本，用作后续聚类与补充来源。

第二阶段 用 raw 侧已完成的题内聚类，按 \(\tau=\lceil K/2\rceil\) 与覆盖簇数 \(C\) 做 **if-else**：

- \(C\ge\tau\)：对同簇多余 random 去重（每簇只留距中心最近的一个，只删不补）；
- \(C<\tau\)：移除全部 random，从 hard/diverse 尚未覆盖的簇中按簇样本量降序取中心代表补齐到 8。

## 四、第一阶段：初始 8 候选抽取

### 4.1 合格题过滤

- 若某题 JPG 数量 **&lt; 40**，跳过，不进入 select/raw 分流。
- 当前合格题：**324** 道。

### 4.2 每题抽取构成

每题抽取 **8** 个样本，来源标签 `selection_source` 为：

| 数量 | 来源 | 含义 |
|------|------|------|
| 4 | `random` | 固定种子（seed=42）随机抽取 |
| 2 | `hard` | 难度样本 |
| 2 | `diverse` | 多样性样本（基于已有融合特征，在非 hard 中最大化两两余弦距离） |

**hard 样本选择规则**：题目为整页 OCR 识别任务，识别难度主要取决于页面信息密度与文本结构复杂度。每题先对全部样本计算三项指标，再按**交替取极值**选出 2 个 hard（实现见 `select_hard_samples`）：

| 指标 | 计算方式 | 含义 |
|------|----------|------|
| 前景像素数 `fg_pixels` | 灰度图中像素值 `< 155` 的像素个数（暗笔迹 / 前景） | 页面墨迹负载；同分辨率下与前景占比等价 |
| Tokens 总量 `token_count` | 对该样本 OCR 全文 `tokenize_greedy` 后的 token 数 | 识别输出长度 / 复杂度 |
| AST 节点数 `ast_node_count` | 该样本 token 序列的 structure-forest AST 节点数 | 数学表达式嵌套与结构复杂度 |

选取步骤（`N_HARD = 2`）：

1. **第 1 个 hard**：在全部样本中按 `(fg_pixels, token_count, ast_node_count)` 降序取最高（前景优先，并列时看 token，再看 AST）；
2. **第 2 个 hard**：在剩余样本中按 `(token_count, ast_node_count, fg_pixels)` 降序取最高（token 优先，并列时看 AST，再看前景）。

审计字段 `selection_rule` 分别为 `max_fg_then_ties` / `max_tokens_then_ties`。这样选中的 hard 同时覆盖“页面最密”与“文本最长”两类难点，用于检验模型识别能力上限。

## 五、剩余样本题内聚类（冻结参考模型）

对 **raw_dataset** 中每题剩余样本聚类。

### 5.1 融合特征流水线（每题独立）

对图像 / 文本原始特征分别：

```text
原始特征
  → 行 L2 归一化
  → 使用该题剩余样本拟合的 PCA（n_components = min(64, N-1)，whiten=False）
  → 行 L2 归一化
```

> 所有入选题均经过 ≥40 样本过滤，PCA 降维到 ≤64 维在此样本量下不存在过拟合风险。

再：

```text
图像 PCA 向量 ∥ 文本 PCA 向量（等权拼接）
  → 整体行 L2 归一化
  → 得到融合向量 Z（典型维度 128）
```

### 5.2 球型 K-means 与 K 选择

- 在单位球上优化，目标与余弦一致；簇中心 \(\mu_k\) 为单位向量。
- 搜索范围：`k_min=2`，`k_max=min(30, N-1)`；每个 \(K\) 独立跑 `n_init=30` 次，取目标最大的一次。
- **Distortion 定义**（spherical K-means 上对 WCSS 的对应形式）：

\[
\operatorname{distortion}(K) = \sum_{i=1}^{N}\bigl(1-\cos(z_i, c_{a_i})\bigr) = N - J(K)
\]

其中 \(J(K)\) 为 clustering objective（余弦和），\(a_i\) 为样本 \(i\) 的簇分配。

- **Elbow 选 \(K_q\)**（实现：`elbow_select_k`，方法名 `max_perpendicular_distance_to_chord`）：在 distortion–\(K\) 曲线上用**归一化端点弦的最大垂直距离**自动定肘点（elbow 直觉的几何自动化，非目视读图）。步骤：
  1. 对曲线做端点归一化：\(x_K=(K-K_{\min})/(K_{\max}-K_{\min})\)，\(y_K=(D(K)-D(K_{\max}))/(D(K_{\min})-D(K_{\max}))\)，使端点为 \((0,1)\) 与 \((1,0)\)，弦方程为 \(x+y-1=0\)；
  2. 点到弦的垂直距离：\(|x+y-1|/\sqrt{2}\)；
  3. 仅在**内部** \(K\in\{K_{\min}+1,\ldots,K_{\max}-1\}\) 中取距离最大者；浮点并列时取更小的 \(K\)。

- 余弦轮廓系数仅作辅助诊断（`silhouette_diagnostic_only`），**不参与** \(K_q\) 选择。

- 典型题内 \(K\) 约在 **6–11**。

### 5.3 每题聚类产物（必须齐全）

路径示例：

## 七、第二阶段具体步骤（逐题）

对每一道合格题 \(q\)，按下列步骤执行。

### 步骤 1：加载冻结聚类与审计

1. 读取 `group_manifest.json`，确认 `status=success`。
2. 加载 `centroids.npy`、`labels.npy`、`fused_features.npy`、`clusters.jsonl`、`image_pca.pkl`、`text_pca.pkl`。
3. 校验：
   - `clusters.jsonl`、融合矩阵、标签**逐行对齐**；
   - 簇中心已单位化；
   - PCA `whiten=False`；
   - 审计中该题恰好 4 random + 2 hard + 2 diverse。
4. 若缺少来源标签、簇中心、样本对齐关系，或无法把 select 样本投到同一融合空间的模型/特征，则**直接失败退出**，不做近似替代。

### 步骤 2：将 8 个候选投影到冻结融合空间

对每个 select 样本，用**该题剩余样本已拟合好的 PCA**，按同一流水线得到 \(Z_x\)：

```text
图像原始特征 → row-L2 → 图像 PCA.transform → row-L2
文本原始特征 → row-L2 → 文本 PCA.transform → row-L2
拼接 → row-L2 → Z_x
```

**禁止**在 8 个候选上重新拟合 PCA，也**禁止**把候选加入聚类训练。

### 步骤 3：按球型规则分配簇

\[
c(x)=\arg\max_k Z_x^\top \mu_k
\]

其中 \(\mu_k\) 为保存的单位簇中心。

同时记录：

- `sample_id`
- `selection_source`（random / hard / diverse）
- `pre_cluster_id`（输出写作 `cluster_x`，避免与数量混淆）
- `pre_cluster_size`
- `pre_cosine_to_centroid`

### 步骤 4：计算修改前簇覆盖数

\[
C_q^{\mathrm{pre}}=\bigl|\{c(x):x\in S_q^{(0)}\}\bigr|
\]

注意：这里统计的是**不同簇的个数**，不是簇编号本身，也不是某一簇内的样本数。

### 步骤 5：判定是否触发修正（当前规则）

阈值取题内聚类数 \(K\) 的一半（向上取整）：

\[
\tau_q=\lceil K_q/2\rceil
\]

示例：\(K=7/8\Rightarrow\tau=4\)，\(K=9/10\Rightarrow\tau=5\)。

**取 half 的理由**：select 作为评测候选集，应当覆盖至少一半的题内数据簇；若实际覆盖不足（\(C<\tau\)），说明 random 样本大概率未能代表该题的数据分布，需要触发全量替换。

`hard` 与 `diverse` 在所有情况下均保留，不参与删除判定。

#### 情况 A：\(C_q^{\mathrm{pre}} \ge \tau_q\)

只处理 `random`：

1. 按簇分组查看全部随机样本；
2. 若某一簇内有**多个**随机样本，仅保留距该簇中心余弦最大者，移除其余随机样本；
3. 不新增样本（最终 select 可能少于 8）。

若每个簇至多 1 个随机样本，则本情况不改动。

#### 情况 B：\(C_q^{\mathrm{pre}} < \tau_q\)（覆盖不足）

1. 移除全部 `random`（通常 4 个）；
2. 在参考聚类中取 **hard/diverse 尚未覆盖的簇** 按簇样本量降序取前 4 个（若不够则顺延到已被覆盖的簇）；
3. 对每个选定簇，在 raw 剩余样本中取距中心余弦最大者作为补充（不得立即使用刚移除的原 random）；
4. 最终 select = 全部 hard/diverse + 4 个中心代表（共 8）。

新增样本 `post_selection_source=replacement`。

### 步骤 6：更新互补数据集

设 \(D_q\) 为移除的 random，\(A_q\) 为新增中心代表（情况 A 时 \(A_q=\varnothing\)）：

\[
S_q^{(*)}=(S_q^{(0)}\setminus D_q)\cup A_q
\]

\[
R_q^{(*)}=(R_q^{(0)}\setminus A_q)\cup D_q
\]

必须满足：

\[
S_q^{(*)}\cap R_q^{(*)}=\varnothing,\quad
S_q^{(*)}\cup R_q^{(*)}=S_q^{(0)}\cup R_q^{(0)}
\]

情况 B 另要求 \(|S_q^{(*)}|=8\)；情况 A 允许 \(|S_q^{(*)}|\le 8\)。

### 步骤 7：记录修改后簇分布

仍使用同一冻结模型，重新统计：

\[
C_q^{\mathrm{post}}=\bigl|\{c(x):x\in S_q^{(*)}\}\bigr|
\]

并写入修改前/后直方图、移除样本原簇、新增样本所属簇及与中心的余弦等审计字段。

输出中凡表示**簇类别**的字段统一写作 `cluster_x`（例如 `cluster_3`），计数值仍为普通整数，避免与簇编号混淆。

## 八、强制验证（失败则非零退出）

运行结束后自动检查，任一失败即打印具体题目与原因并退出：

1. `hard` / `diverse` 始终保留；
2. \(C\ge\tau\)：仅对同簇多随机做去重（每簇保留距中心最近的一个 random），不新增；
3. \(C<\tau\)：移除全部 random，并从 hard/diverse 尚未覆盖的簇中按簇样本量降序取中心代表补齐到 8；
4. 新增样本来自原 raw，且为对应簇中距中心最近的可用真实样本；
5. 最终 select 与 raw 无交集；
6. 最终 select ∪ raw 与阶段一全集一致（无丢失、无重复）；
7. 所有 JPG 均有配对 JSON，物化路径存在；
8. 相同输入与配置重复运行结果一致。

## 九、结果摘要（题内修正 → 全局去重）

### 9.1 题内第二阶段 if-else（`run_stage2.py`）

阈值 \(\tau=\lceil K/2\rceil\)。对**每一道题**的题内冻结簇做 **if-else**（二者互斥）：

- **\(C\ge\tau\)**：只检查该题 `random` 是否落在同一**题内**簇；若同一簇内有多个 random，仅保留距该簇中心余弦最大者，移除其余；不新增；`hard` / `diverse` 不动。
- **\(C<\tau\)**：移除全部 4 个 `random`；在 hard/diverse 尚未覆盖的题内簇中按簇样本量降序取中心代表补 4 个（不够再顺延）；标记 `replacement`。

历史物化 `stage2_cluster_adjusted_1`：当时 \(C\ge\tau\) **整题保留**（未做同簇 random 去重），仅 \(C<\tau\) 更换 → select 仍为 **2592**（random 792 + hard 648 + diverse 648 + replacement 504）。

按**当前**完整 if-else 对 324 题复算：\(C\ge\tau\) 额外移除约 **123**，select 约为 **2469**（\(C<\tau\) 更换不改变总数）。

### 9.2 全局簇 random 去重（`global_random_dedupe.py` → `adjusted_2`）

在题内修正后的 select（金标准输入为 `adjusted_1` 的 2592 对）上，再按**全局聚类** `cluster_id`（跨题，本批为 13 个全局簇）去重：

- 仅处理 `post_selection_source == random`；
- **每个全局簇最多保留 1 个 random**（余弦最大；并列取更小 `sample_id`）；
- `hard` / `diverse` / `replacement` 全部保留。

| 指标 | 数值 |
|------|------|
| 输入 select | **2592** |
| 输出 select（`stage2_cluster_adjusted_2`） | **1813** |
| 净移除 | **779**（全部为多余 random） |
| 保留 random | **13**（= 有 random 的全局簇数） |

来源构成（`adjusted_2`）：hard 648 + diverse 648 + replacement 504 + random 13 = **1813**。

> 注意：这一步用的是**全局簇**，不是题内 \(K_q\) 簇；与 §7 / §9.1 的 \(\tau\) if-else 不是同一步。

### 9.3 数量链路（对照）

```text

        │
        ▼ 题内 if-else（τ=⌈K/2⌉；历史 adjusted_1：C≥τ 未去重 → 仍 2592）
stage2_cluster_adjusted_1       2592
        │
        ▼ 全局簇 random 去重（每全局簇至多 1 个 random；−779）
```

## 十、Seed 2.1 Pro 知识点标注与最终筛题

在题内修正并经**全局簇 random 去重**得到 `stage2_cluster_adjusted_2`（1813 对，324 道题）后，还需对每道题进行知识点分析并剔除标签不合理的题目。

### 输入与工具

| 项目 | 路径 |
|------|------|
| 候选题目录 | `stage2_cluster_adjusted_2/select_dataset`（324 道题，1813 对；标注亦可对照修正前的 2592 对全集） |
| 知识点框架 | `tools/candidate_select_cluster/docs/高中数学三级标签框架_一级与二级优化版_v0.2.md` |
| 标注工具 | `tools/seed21pro_tools/`（内部调用 `src/qa_latex_transcribe/label_taxonomy.py`） |

### 标注流程

1. **Q/A LaTeX 转录**：对每道题的 Question 和 Answer 做 LaTeX 格式转换，确保数学公式可解析；
2. **学生 OCR 填充**：对每道题填充 10 份学生手写作答 OCR 文本（`Student_1` ~ `Student_10`），用于上下文辅助判断；
3. **多级知识点标注**：基于上述三级标签框架，对每道题输出一级标签（4 大类）和二级标签（27 子类）；
4. **GPT 核验**：以上三步由 `seed21pro_tools` 工具链自动完成，知识点标注结果完全可复现。GPT 仅作为评判官对标注结果进行人工辅助核验，确认标签合理性并调整有争议的标注，不影响核心标注过程的可复现性。

### 输出

```text
tools/candidate_select_cluster/data/第二批数据题目_seed21pro_latex.csv
```

CSV 字段：`题目名`, `Question`, `Answer`, `Student_1`~`Student_10`, `Label_level_1`, `Label_level_2`。

每道题可对应多行（同一题目可能有多个二级标签），共 **491 行**，覆盖 **324 个唯一题目**，**全部 324 题均已标注**。一级标签分布：

| 一级标签 | 出现次数 |
|----------|----------|
| 函数 | 191 |
| 几何与代数 | 155 |
| 预备知识 | 77 |
| 概率与统计 | 68 |

二级标签共 27 个类别。

## 十、审计文件怎么读

- `added.by_cluster`：新增代表按所属簇 → 文件名
